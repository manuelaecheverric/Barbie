# Datos del Agente Barbie

- `corpus/`: fichas que se cargan al inicio en la base vectorial (12 archivos .md).
- `demo/`: documento que NO se carga al inicio. Se sube en vivo durante la sustentación
  para mostrar que el agente aprende de documentos nuevos.

Pregunta de la demo: "¿Cómo se llama la unicornio de El lago de los cisnes?"
- Antes de subir el documento → rechazo.
- Después de subirlo → "Lila".
